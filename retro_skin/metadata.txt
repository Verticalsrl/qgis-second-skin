about=Retro Skin is a playful plugin for GIS nostalgics: it does not add any analysis feature, it just dresses QGIS up like the desktop GIS of the '90s and early 2000s, for a smile and a trip down memory lane.

    Included skins: Vintage 95, ArcView 3.x style, ArcMap 8.x style. Switch skins from Plugins > Retro Skin, from the toolbar button or with Ctrl+Alt+K; "QGIS (original)" restores the standard look.

    Everyone is free to create and share their own skins: a skin is just a folder with a skin.json file, a Qt stylesheet (style.qss) and 16/32 px PNG icons. Copy an existing skin folder, edit it, and it will show up in the menu. See the README in the repository for the format.

    All icons are original pixel art. ArcView and ArcMap are trademarks of Esri. Retro Skin is an independent project, not affiliated with or endorsed by Esri: skin names only describe a visual style.
